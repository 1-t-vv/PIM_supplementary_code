# Rollout Comparison Materials

The scope:

- `pim_evaluation/` is a complete, runnable release of the PIM experiment used in the
  controlled Flat rollout comparison. It includes PIM's test store, cache, checkpoint,
  recorded predictions/results, and evaluator.
- `baseline_code/` is a code-reference release for the six autoregressive baselines. It
  contains their model implementations only.

 See the README in each subdirectory for the precise file map and PIM
evaluation command.
